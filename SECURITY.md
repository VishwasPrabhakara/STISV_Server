# Security Policy

This repository is a public engineering showcase of the STIS-V 2025 conference
platform. It must not contain participant records, payment data, service-account
files, private keys, or production environment values.

## Reporting a vulnerability

Please do not open a public issue for a security or privacy problem. Report it
privately to the repository owner through the contact information on the
[GitHub profile](https://github.com/VishwasPrabhakara).

Include the affected route or component, reproduction steps, and potential
impact. Do not access, modify, or retain real participant data while testing.

## Supported version

Security fixes are applied to the default branch. The public conference is now
a post-event archive, while protected registration, submission, administration,
and payment code remains documented for engineering review.
